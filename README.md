# BLSM

Landing estática para presentar dulces regionales de México. Puede publicarse directamente con GitHub Pages, sin proceso de compilación.

## Estructura

```
.
├── index.html          # Punto de entrada publicado por GitHub Pages
└── src/
    ├── css/
    │   └── main.css    # Estilos, variables y diseño adaptable
    ├── js/
    │   └── app.js      # Datos de estados e interacciones
    └── images/         # Recursos visuales propios del proyecto
```

Agrega imágenes optimizadas (WebP o SVG cuando sea posible) en `src/images/` y usa rutas relativas desde `index.html`, por ejemplo `src/images/producto.webp`.
